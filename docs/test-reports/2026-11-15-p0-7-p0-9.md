## Facts checked against the CLIs (Gemini CLI 0.68.0 source and runs, agy 1.5.9 binary and runs)

1. Gemini `hookSpecificOutput.hookEventName` (tester's open item): Gemini reads only
   `hookSpecificOutput.additionalContext` (string; `<`/`>` escaped) and ignores `hookEventName`. Harmless; kept.
2. Gemini matches a `SessionStart`/`SessionEnd`/`PreCompress` matcher to the trigger by **plain equality**, not regex.
   The research example `"startup|resume"` never fires. Our SessionStart has no matcher.
3. Gemini fires `PreCompress` (trigger `auto`) **before every turn**, ahead of its threshold check, and waits for it.
   Fixed: Gemini `precompact` starts a detached flush instead of a 20 s synchronous one.
4. Gemini `-p` prepends `<hook_context>…</hook_context>` to the prompt and `AfterAgent.prompt` echoes it. Fixed:
   the Gemini adapter strips those blocks before capture (otherwise recalled text is stored again every turn).
5. Gemini passes extension settings (`RUSHDB_API_KEY`, `RUSHDB_API_URL`, `RUSHDB_AUTO_CONTEXT`) into hook env;
   `${VAR:-default}` works in the manifest. The sensitive key goes to the **system keyring** (Secret Service) when one
   is reachable, even with a scratch `HOME`; in tests set `DBUS_SESSION_BUS_ADDRESS=unix:path=/nonexistent` so it
   falls back to `$HOME/.gemini/gemini-credentials.json`. Also unset `XDG_STATE_HOME`/`XDG_CONFIG_HOME`, or the
   hooks use the real `~/.local/state/rushdb` and `~/.config/rushdb`.
6. agy hook stdin (live): `conversationId`, `cwd`, `workspacePaths`, `transcriptPath`, `lastUserInput`,
   `hookEventName`, `modelName`, `artifactDirectoryPath`; `Stop` adds `terminationReason` etc. and **no answer
   text**, so agy capture stays off (SessionStart recall only). Hooks run in the plugin folder with `PLUGIN_ROOT` and
   `PLUGIN_DATA`, but **not** the MCP `variables`: the hook key comes from `RUSHDB_API_KEY` in the shell or
   `~/.config/rushdb/config.json`. Timeouts are seconds. Rules need `trigger: always_on` front matter, and
   `rules/rushdb.md` says the hooks only recall there.
8. agy MCP configs expand only `${NAME}` placeholders declared in `variables`, with no default values, and keep the
   plugin off until every variable is filled in. `mcp_config.json` declares `RUSHDB_API_KEY` and `RUSHDB_API_URL`;
   the URL's description names the Cloud URL, which Cloud users enter on the setup form.
7. `agy plugin install <path>` copies the whole folder (a local worktree with `node_modules` is 425 MB). A GitHub
   install clones tracked files only. `commands/` is converted to a skill by agy on install.
