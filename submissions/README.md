# Submissions

Drafts of every listing and directory submission for the RushDB agent plugins.
Agents write and update these packets; **the owner submits** every listing, form
and community-index PR.

| Packet                     | Listings                                                    |
| -------------------------- | ----------------------------------------------------------- |
| [claude.md](claude.md)     | Claude directory: hosted MCP connector and the plugin bundle |
| `openai.md` (planned)      | OpenAI app directory (ChatGPT and Codex)                    |
| `deepseek.md` (planned)    | DeepSeek Harness program and community indexes              |
| `modelscope.md` (planned)  | ModelScope MCP Plaza                                        |

Rules for every packet:

- No credentials, tokens or test logins. Reviewers get test access by email when
  they ask.
- Public product facts only: no usage, customer, revenue or infrastructure
  figures.
- Listing text comes from `shared/listing.json`, so the packets and the
  manifests never disagree.
